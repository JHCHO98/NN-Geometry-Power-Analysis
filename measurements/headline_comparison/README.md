# Headline Comparison: 0551 vs C002793

This comparison measures two trained ONNX models with similar parameter counts:
the VGG-inspired reference 0551 and final Pareto candidate C002793 (model
0530). The trained artifacts belong in `onnx/` using the names generated by
`prepare_headline_comparison.py`.

First create the two-model training input, then train with the same CIFAR-10
protocol used for all accuracy labels. This stores both selected checkpoints
and trained ONNX artifacts in the expected paths:

```powershell
.\.venv\Scripts\python.exe prepare_headline_training_inputs.py
.\.venv\Scripts\python.exe train_candidate_accuracy.py `
  --candidates-csv measurements\headline_comparison\headline_training_candidates.csv `
  --output-csv measurements\headline_comparison\headline_training_results.csv `
  --trained-artifact-dir measurements\headline_comparison `
  --epochs 30 --batch-size 128 --lr 0.001
.\.venv\Scripts\python.exe prepare_headline_comparison.py --require-artifacts
```

On Colab, run the same commands after mounting Drive and changing to the
repository directory. The final command replaces the older recorded accuracy
with the newly trained models' best validation accuracy in `headline_models.csv`.

Run four measurements per model through two balanced blocks (ABBA then BAAB):

```powershell
.\.venv\Scripts\python.exe prepare_headline_comparison.py --require-artifacts
.\.venv\Scripts\python.exe run_weight_state_paired_benchmark.py `
  --pair-manifest measurements\headline_comparison\headline_manifest.csv `
  --benchmark-session-id headline_20260920_s01 `
  --result-csv measurements\benchmark_runs\headline_0551_vs_0530.csv `
  --state-a reference_0551_trained `
  --state-b pareto_0530_trained `
  --protocol-id headline_trained_abba_v1 `
  --abba-blocks 2 --cpu-core 0 --high-priority
```

Save the continuous HWiNFO log as
`measurements/raw_hwinf/headline_0551_vs_0530.csv`, then run:

```powershell
.\.venv\Scripts\python.exe analyze_energy.py `
  --hwinfolog measurements\raw_hwinf\headline_0551_vs_0530.csv `
  --benchmark-csv measurements\benchmark_runs\headline_0551_vs_0530.csv `
  --output-dir measurements\headline_comparison\processed
.\.venv\Scripts\python.exe analyze_headline_comparison.py `
  --benchmark-session-id headline_20260920_s01
```

The analysis writes trial counts, mean and standard deviation for trained
energy (mJ) and latency (ms), relative change against 0551, and a PNG chart.
