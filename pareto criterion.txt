1. Confidence interval 정의

각 후보 (i)에 대해 confidence multiplier (k)를 사용하여 다음 interval을 정의한다.

[
E_i^- = \mu_{E,i} - k\sigma_{E,i}
]

[
E_i^+ = \mu_{E,i} + k\sigma_{E,i}
]

[
A_i^- = \mu_{A,i} - k\sigma_{A,i}
]

[
A_i^+ = \mu_{A,i} + k\sigma_{A,i}
]

여기서 Energy는 낮을수록 좋으므로

E_minus = 해당 후보가 잘 나왔을 때의 Energy

E_plus = 해당 후보가 나쁘게 나왔을 때의 Energy

Accuracy는 높을수록 좋으므로

A_minus = 해당 후보가 나쁘게 나왔을 때의 Accuracy

A_plus = 해당 후보가 잘 나왔을 때의 Accuracy

이다.

2. 가장 엄격한 Certified Pareto 정의

후보 (i)를 Certified Pareto라고 인정하려면,

후보 (i)의 실제 성능이 confidence interval 안에서 가장 나쁘게 나오고,
경쟁 후보 (j)의 실제 성능이 confidence interval 안에서 가장 좋게 나오더라도,
어떤 (j)도 (i)를 Pareto-dominate할 수 없어야 한다.

후보 (j)가 후보 (i)를 "potentially dominate"할 수 있는 조건은

[
E_j^- \le E_i^+
]

그리고 동시에

[
A_j^+ \ge A_i^-
]

이다.

Pareto dominance에서는 적어도 하나의 inequality가 strict해야 한다.

즉 다음을 만족하는 (j \ne i)가 하나라도 존재하면 후보 (i)는 Certified Pareto가 아니다.

[
E_j^- \le E_i^+
\quad\text{and}\quad
A_j^+ \ge A_i^-
]

(with at least one strict inequality)

따라서 Certified Pareto의 기준은

[
\boxed{
\forall j\neq i,\quad
E_j^- > E_i^+
\quad\text{or}\quad
A_j^+ < A_i^-
}
]

이다.

이 기준은 다음 의미를 가진다.

"내 Energy가 +kσ만큼 나쁘게 나오고 Accuracy가 -kσ만큼 나쁘게 나오며,
경쟁자는 Energy가 -kσ만큼 좋게 나오고 Accuracy가 +kσ만큼 좋게 나오더라도,
경쟁자가 나를 dominate하지 못한다."

이 기준을 최우선 기준으로 사용해라.

3. k 값

k는 configurable parameter로 구현한다.

기본적으로 다음 값을 테스트할 수 있게 해라.

k = 1.96: 대략적인 개별 95% interval

k = 3.0: 상당히 보수적인 기준

k ≈ 5.0: 매우 보수적인 기준

50,000개의 후보에 Energy와 Accuracy 두 예측값이 있으므로 총 약 100,000개의 uncertain quantities가 존재한다.

정규분포를 가정하고 전체 예측값에 대해 매우 보수적인 simultaneous confidence를 적용하고 싶다면 Bonferroni-style 보정으로 약 k ≈ 5.0 수준도 고려할 수 있다.

단, 이것은 예측분포가 Gaussian이라고 가정했을 때의 접근이다.

코드에서는 k를 반드시 외부 parameter로 받을 수 있게 구현해라.

4. 계산 복잡도

데이터가 약 50,000개이므로 모든 pair를 비교하는 단순한

[
O(N^2)
]

알고리즘은 피하고 싶다.

2차원이라는 점을 이용해 가능하면

[
O(N \log N)
]

수준으로 구현해라.

Certified 여부를 판단할 때 후보 (i)에 대해서 필요한 것은 본질적으로

[
E_j^- \le E_i^+
]

를 만족하는 모든 후보 (j) 중에서

[
\max_j A_j^+
]

가 (A_i^-) 이상인지 확인하는 것이다.

따라서 다음과 같은 sweep-line / sorting 접근을 고려해라.

모든 후보를 E_minus 기준으로 오름차순 정렬한다.

각 후보 (i)의 query threshold는 E_plus[i]이다.

E_minus[j] <= E_plus[i]인 후보들을 sweep하면서 A_plus의 최대값을 관리한다.

최대 A_plus가 A_minus[i]보다 크거나 같다면 잠재적으로 (i)를 dominate하는 후보가 존재한다.

단, 자기 자신 j == i는 competitor에서 제외해야 한다.

자기 자신이 현재 최대값인 경우를 정확히 처리하기 위해 필요하다면 가장 큰 A_plus와 두 번째로 큰 A_plus, 그리고 해당 index를 관리해라.

equality의 경우 Pareto dominance의 "at least one strict inequality" 조건을 정확히 처리해라.

숫자 안정성 때문에 floating-point 비교에 작은 tolerance eps를 둘 수 있도록 구현해라.

5. 같이 계산했으면 하는 비교 기준

최종 결과에서는 Certified Pareto뿐 아니라 아래 세 종류를 같이 계산해 비교할 수 있게 해라.

A. Mean Pareto

평균값만 사용한다.

후보 (j)가 (i)를 dominate하는 조건:

[
\mu_{E,j} \le \mu_{E,i}
]

[
\mu_{A,j} \ge \mu_{A,i}
]

그리고 적어도 하나는 strict inequality.

이 기준의 Pareto set을 mean_pareto라고 한다.

B. Non-certainly-dominated / Possible Pareto

반대 방향의 uncertainty 기준도 계산한다.

후보 (j)가 후보 (i)를 확실하게 dominate하려면,

(j)가 가장 나쁘게 나오고 (i)가 가장 좋게 나와도 dominance가 성립해야 한다.

즉

[
E_j^+ \le E_i^-
]

그리고

[
A_j^- \ge A_i^+
]

이어야 한다.

이러한 (j)가 존재하지 않는 후보들을 possible_pareto 또는 not_certainly_dominated라고 정의해라.

일반적으로

[
\text{Certified Pareto}
\subseteq
\text{Mean Pareto 부근}
\subseteq
\text{Possible Pareto}
]

와 같은 관계가 나타날 것으로 기대한다. 단, 실제 set 포함관계는 데이터와 정의/tie 처리에 따라 확인해서 보고해라.

C. Certified Pareto

가장 중요한 결과이다.

앞에서 정의한

[
\forall j\neq i:
E_j^- > E_i^+
\quad\text{or}\quad
A_j^+ < A_i^-
]

조건을 사용한다.

6. 가능하면 Pareto probability도 추가

추가적으로 computationally feasible하다면 Monte Carlo 방식으로 각 후보의

[
P(i\text{ is Pareto})
]

를 추정하는 함수도 만들어라.

Gaussian prediction을 가정하면 각 simulation (s)에서

[
E_i^{(s)}
\sim
N(\mu_{E,i},\sigma_{E,i}^2)
]

[
A_i^{(s)}
\sim
N(\mu_{A,i},\sigma_{A,i}^2)
]

를 sampling한다.

매 simulation마다 일반적인 Pareto front를 구한 뒤

[
P_i =
\frac{
\text{후보 i가 Pareto에 포함된 simulation 횟수}
}{
N_{\mathrm{MC}}
}
]

로 계산한다.

예를 들어

P(Pareto) >= 0.95

P(Pareto) >= 0.99

등을 추가적인 selection criterion으로 사용할 수 있게 해라.

단, 50,000개 × 많은 Monte Carlo sample은 계산량이 클 수 있으므로 효율적인 2D Pareto 알고리즘을 사용해라.

Monte Carlo는 optional 기능으로 구현해도 된다.

7. Correlation 관련

현재 기본 입력은 Energy와 Accuracy 각각의 sigma만 있다고 가정한다.

따라서 기본 구현에서는 Energy/Accuracy prediction error를 independent Gaussian으로 처리해도 된다.

하지만 만약 각 후보별로 Energy와 Accuracy prediction error 사이의 correlation coefficient

rho[i]

가 추가로 주어질 경우, Monte Carlo 함수에서는 bivariate Gaussian으로 joint sampling할 수 있도록 확장 가능한 구조로 만들어라.

가능하다면 후보들 간 prediction error correlation까지 있는 경우에는 단순 marginal interval 방식보다 joint posterior sampling이 더 적합하다는 점도 설명해라.
